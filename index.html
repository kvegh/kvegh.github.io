Advanced AAP usecases

13 automation projects and supporting tools, with technical documentation and visual walkthroughs where available. Umbrella repository ↗

01

Disconnected environments

Disconnected Windows Patching

Automates Windows OS and application patching in disconnected environments using WSUS, Chocolatey and Nexus. It covers controlled content transfer, named patch baselines, managed updates and application upgrades through AAP.

02

Targeted patching

RHEL Sniperpatching

Demonstrates targeted RHEL patching by security advisory or CVE using Red Hat Satellite and AAP. Staged Test-to-Production promotion and package-level verification connect selected fixes to their actual outcomes.

Repository ↗
03

Event-driven automation

AIOps Self-Healing Demo

Connects Zabbix monitoring, Event-Driven Ansible, AI assistance and AAP remediation. A website outage provides a visible scenario for detecting a problem, triggering automation and verifying recovery.

Repository ↗Visualization ↗
04

Inventory-driven configuration

Configuration Exception Handling

Expresses host and group differences as inventory data while keeping shared Ansible automation consistent. Platform, application, lifecycle and compliance requirements remain reviewable in Git.

Repository ↗
05

Configuration as code

RHEL Configuration as Code

Scans selected RHEL configuration and stores it as encrypted configuration as code for repeatable deployment. The initial scope covers local accounts, SSH public keys, sudo access and SSH authentication settings.

Repository ↗
06

IT service management

ServiceNow ITSM Integration

Plans AAP integrations for ServiceNow incident management, service-catalog fulfillment and CMDB reconciliation. The repository currently documents the proposed demonstration and implementation work.

Repository ↗
07

Repeatable platform deployment

AAP AutoDeploy & Configuration as Code

Automates AAP environment deployment, from VM provisioning and platform installation to configuration-as-code imports. It also aims to scan and extract the configuration of running AAP instances for reproducible recovery and deployment.

Repository ↗Visualization ↗
08

Automation orchestration

Automation Orchestrator

Provides automation for deploying Automation Orchestrator on OpenShift with its database and AAP integration. The repository covers installation and cleanup, with runtime verification tracked separately from configuration import.

Repository ↗
09

AI-assisted automation

AAP Intelligent Assistant

Documents AAP Intelligent Assistant setup with an OpenAI-compatible language-model backend and MCP integration. Reproducible instructions and issue records explain chatbot configuration and provider compatibility.

Repository ↗
10

Self-service automation

Automation Portal Setup

Explores the Ansible automation portal as a self-service catalog for AAP job templates. It documents a RHEL appliance deployment on KVM with cloud-init, AAP authentication and catalog synchronization.

Repository ↗
11

Automation analytics

Automation Dashboard

Generates representative demo job activity for AAP usage statistics and return-on-investment reporting. Simulated maintenance runtimes provide sample data for demonstrating Automation Analytics.

Repository ↗
12

Inventory & source of truth

CMDB for AAP

Explores Git records, ServiceNow CMDB and gathered Ansible facts as sources of authoritative host information for AAP. The initial Git-based record exists, while the ServiceNow and fact-generated variants are planned.

Engineering practice

Agent-generated Code Review

Defines review requirements for AI-generated Ansible automation and its supporting code. It covers maintainability, security, supported execution environments and evidence-based verification.
